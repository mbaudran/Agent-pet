# Keloqz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Keloqz, a floating pixel German Shepherd for macOS that shows every running Claude Code session and delivers Lomo-Saltado's "¡Saltado!" notifications, then retire MasIAPet.

**Architecture:** A SwiftPM package with two targets: `KeloqzCore` (pure, unit-tested logic: session merging, turn detection, notification queue, pose choice, heartbeat, geometry) and `Keloqz` (AppKit + SwiftUI shell: floating panel, sprite player, bubble, toolbar, session list, Terminal automation). The sprites are rendered once by a Node script from the approved JS drawing code, and Swift only plays the PNG strips. A one-function change to the Lomo-Saltado mod makes it skip macOS banners while Keloqz's heartbeat is fresh.

**Tech Stack:** Swift 6.4 toolchain (language mode 5), AppKit + SwiftUI, Swift Testing, Node 26 (built-ins only), AppleScript (Terminal), ServiceManagement (`SMAppService`), the Claude Code mod runtime (TypeScript) for Lomo-Saltado.

**Spec:** `keloqz/docs/specs/2026-10-23-keloqz-design.md`. Read it before starting any task.

## Global Constraints

- No Xcode. Build and test with `SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk` and SwiftPM's **default** build system (verified 2026-10-24: `@State` and Swift Testing both compile; `--build-system native` cannot find `Testing`).
- Tests use **Swift Testing** (`import Testing`, `@Test`, `#expect`). XCTest is not installed.
- `swift-tools-version:6.0`, `platforms: [.macOS(.v14)]`, every target `swiftSettings: [.swiftLanguageMode(.v5)]`.
- No third-party Swift packages and no npm dependencies. Node scripts use built-ins only.
- On-screen text is in Spanish.
- Files: `~/.claude/sessions/<pid>.json`, `~/.claude/saltado/cocina/<sessionId>.json`, `~/.claude/saltado/keloqz.json`.
- Timings: heartbeat every **10 s**, mod treats it as stale after **30 000 ms**, fallback re-read every **3 s**, non-sticky bubble **6 s**, sticky when the turn lasted **> 120 s**, `done` pose for **2 s**, sleep after **5 min**, click/drag threshold **3 pt**.
- Scales: S/M/L = **2×/3×/4×**, default **2×**. Sprite grid **48 px** tall.
- Bundle id `com.mba.keloqz`, app name `Keloqz`, `LSUIElement` true.
- Push to `mbaudran/Lomo-Saltado-Claude-mod` and every MasIAPet removal step **only after the user confirms**.

## Review Focus

1. **A session closed mid-turn** (terminal killed while cooking) must vanish from the list without a "¡Saltado!" bubble. Test: `vanishedWhileCookingEmitsNothing` (Task 3).
2. **A turn aborted with Esc** must not trigger a bubble, matching the mod, which never notifies aborted turns. The cocina file doesn't record this today, so Task 9 adds `aborted` to it and Task 3 tests `abortedTurnEmitsNothing`.
3. **Two sessions with the same name** (two terminals in `PRJ_P` are both called "PRJ_P" right now) must stay tellable apart: append ` · ` plus the first 4 characters of the sessionId to every colliding name. Test: `duplicateNamesGetShortIdSuffix` (Task 2).
4. **Multi-line, very long or emoji-heavy prompts** in the bubble: collapse whitespace and truncate at 60 grapheme clusters with "…", never splitting an emoji. Test: `bubbleTextCollapsesAndTruncatesByGrapheme` (Task 3).
5. **A monitor unplugged or rearranged** while Keloqz sat on it must bring the dog back onto a visible screen. Test: `clampMovesOffscreenPanelOntoNearestScreen` (Task 5).

### Task 3: Turn detection, notification queue and bubble text

**Interfaces:**
- Consumes: `Session` (Task 2).
- Produces:

```swift
public struct TurnFinished: Equatable, Sendable {
  public let sessionId: String; public let name: String; public let dish: String  // bubbleText(dish) or ""
  public let duration: TimeInterval; public let ok: Bool; public let sticky: Bool    // sticky = duration > 120
}
public struct TurnWatcher { public init(); public mutating func update(_ sessions: [Session]) -> [TurnFinished] }
public struct NotificationQueue {
  public init(); public private(set) var current: TurnFinished?
  public mutating func push(_ turns: [TurnFinished], now: Date)
  public mutating func advance(now: Date)     // drops a non-sticky current after 6 s, then shows the next
```

- Emit rules (spec §6.3):
  - The first `update` is the baseline and returns `[]`.
  - Emit when a session that has `hasCocina` either goes from `isCooking` to `!isCooking`, or keeps `!isCooking` while its `endedAt` moves forward.
  - Never emit for sessions without cocina (the mod doesn't notify for them either).
  - Never emit when `aborted`, when `endedAt` or `startedAt` is `nil`, or when the session disappeared.
  - `ok = errors == 0`.
